Backup and restore for the data your cluster runs on

planb is a Kubernetes operator that backs up PostgreSQL databases and S3 buckets to any S3-compatible object store, and brings them back when you need them. It works like Velero, but for data services.

Get started How it works

What it backs up

Backups go to AWS S3, MinIO, Ceph RGW, Cloudflare R2 or any other S3-compatible store.

PostgreSQL

One binary pg_dump archive per database, or the whole server with pg_dumpall. Restore in place, under a new name or onto another server.

S3 buckets

Snapshot every object in a bucket or under a prefix. Restore it anywhere, and optionally prune the target so it matches the snapshot exactly.

Notifications

A message on Telegram, Slack, a webhook or email when a backup or restore finishes or fails.

Built to be trusted

Each backup or restore runs as a Kubernetes Job that streams data straight to object storage.

Rides out outages

Retries with exponential backoff at three levels, resumable downloads and listings, and PostgreSQL-aware rules so a restore is never repeated in a way that could corrupt it.

Ready for disaster recovery

Point a new cluster at the same bucket and planb imports the backups it finds there. The format is plain files you can also restore by hand.

Schedules and retention

Cron schedules with time zones, keep-last-N, TTLs, and data that is deleted with its Backup, unless you choose to keep it.

Credentials stay in Secrets

Jobs read credentials only through secretKeyRef, run as non-root on a read-only filesystem, and stream without touching local disk.

Five resources

All namespaced, in the API group planb.sina-devel.github.io/v1alpha1.

KindPurpose
BackupStorageLocationThe bucket backups are written to. Checked periodically and synced back into the cluster.
BackupA one-off backup of a PostgreSQL server or a bucket.
ScheduleCreates Backups on a cron schedule and keeps the last N.
RestoreRestores a Backup to its original source or a different target.
NotifierSends a message when backups or restores finish.

Quick start

Install the operator, then follow Getting started for your first backup and restore.

git clone https://github.com/sina-devel/planb && cd planb
helm upgrade --install planb charts/planb -n planb-system --create-namespace
