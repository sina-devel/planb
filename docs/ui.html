Web UI

An optional single-page UI to watch backups, run them, restore with a few clicks and read job logs.

Enable it#

helm upgrade --install planb charts/planb -n planb-system --reuse-values \
  --set ui.enabled=true \
  --set ui.auth.username=admin --set ui.auth.password='a-long-random-password'

Open it with a port-forward:

kubectl port-forward -n planb-system svc/planb-ui 8090:80
# http://localhost:8090

Or expose it through an Ingress:

ui:
  ingress:
    enabled: true
    className: traefik             # or nginx, ...
    host: planb.example.com
    tls: [{ secretName: planb-tls, hosts: [planb.example.com] }]
Set authentication before exposing it

The UI can create restores and delete backups. Use ui.auth, or ui.auth.existingSecret pointing at a Secret with username and password keys, or put it behind your own authenticating proxy. For a view-only dashboard, set ui.readOnly: true.

What it does#

  • Lists storage locations, backups, schedules, restores and notifiers in every namespace (or one, with ui.namespace), refreshing every 5 seconds, with filters and pagination.
  • Backups: create one from a form or a JSON spec, delete, view the Job's logs.
  • Restore from any completed backup: target server or bucket, database mapping, clean, overwrite and prune.
  • Schedules: create, Run now, pause and resume.
  • Storage locations and notifiers: create them, including their Secrets, and send a test message.

JSON API#

The UI is one embedded HTML file with no build step, talking to a small JSON API that you can script against. The API uses the same basic auth.

Method and pathDoes
GET /api/overviewAll resources the UI can see
GET /api/configRead-only mode and namespace restriction
GET /api/logs/{ns}/{job}Logs of a backup or restore Job
POST /api/backups{namespace, name?, spec}, or {namespace, schedule} for "run now"
POST /api/restores{namespace, name?, spec}
POST /api/schedules, /api/storagelocations, /api/notifiers{namespace, name, spec, secrets?}; secrets are created first and never overwritten
POST /api/schedules/{ns}/{name}/{pause|resume}Pause or resume
POST /api/notifiers/{ns}/{name}/testSend a test message
DELETE /api/{kind}/{ns}/{name}Delete a backup, restore, schedule, storage location or notifier
 
curl -u admin:$PASS -H 'Content-Type: application/json' -X POST http://localhost:8090/api/restores \
  -d '{"namespace":"db","name":"app-check","spec":{"backupName":"app-1","postgres":{"databaseMapping":{"app":"app_check"}}}}'
