Development

Build planb, run it against a cluster from your machine, and run the unit, agent and cluster test suites.

Setup#

The repository has a Nix dev shell with Go, controller-gen, Helm, kind, PostgreSQL and rclone. Without Nix, install those yourself; make generate falls back to go run for controller-gen.

nix develop            # or nix-shell, or direnv allow
make tidy generate     # dependencies, deepcopy code, CRDs and RBAC
make build             # bin/planb

Layout#

api/v1alpha1/         CRD types; `make generate` writes charts/planb/crds/
cmd/planb/            one binary: manager | agent | ui
internal/controller/  reconcilers: backup, restore, schedule, storage location, notifier
internal/agent/       data movers inside Jobs: pg_dump/pg_restore, bucket copy and prune
internal/storage/     S3 client (minio-go) with resumable reads and listings
internal/retry/       exponential backoff with jitter
internal/notify/      Telegram, Slack, webhook and email senders
internal/task/        the operator ↔ agent contract (PLANB_TASK JSON, termination message)
internal/ui/          UI server and its single embedded HTML page
charts/planb/         Helm chart
docs/                 this website (static HTML, deployed by .github/workflows/pages.yaml)
hack/                 demo manifests and end-to-end tests

Run locally#

make install           # CRDs into the current kubeconfig context
make run               # the operator, from your machine
make run-ui            # the UI on http://localhost:8090

The operator still starts Jobs in the cluster, so IMG must point at an image the cluster can pull: make run IMG=localhost:5000/planb:dev.

Images#

.github/workflows/image.yaml runs the tests and publishes multi-arch images to ghcr.io/sina-devel/planb on every push to main and on v* tags. To test a build in a local cluster such as k3s with a local registry:

make docker-build docker-push IMG=localhost:5000/planb:dev
kubectl apply --server-side -f charts/planb/crds
helm upgrade --install planb charts/planb -n planb-system --create-namespace \
  --set image.repository=localhost:5000/planb --set image.tag=dev --set image.pullPolicy=Always

This website#

The site is plain HTML in docs/, with shared styles in docs/assets/site.css. Edit the pages directly; a push to main that changes docs/ deploys it to GitHub Pages. When you add a page, add it to the sidebar of every page and to the previous/next links of its neighbours.

Roadmap#

  • Client-side encryption of backups (age/AES) and checksums in the metadata
  • More databases: MySQL/MariaDB, MongoDB, Redis
  • Point-in-time recovery for PostgreSQL (WAL archiving)
  • Prometheus metrics for backup age, size and failures
  • Incremental bucket backups
