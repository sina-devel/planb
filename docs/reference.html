API reference

Every field of every planb resource. API version planb.sina-devel.github.io/v1alpha1; all resources are namespaced.

The CRDs carry the same descriptions, so kubectl explain backup.spec.postgres works too. Defaults are applied by the API server.

BackupStorageLocation#

Short name bsl. An S3-compatible bucket that stores backups.

FieldTypeDefaultDescription
spec.s3S3SpecThe bucket. Required.
spec.accessModestringReadWriteReadWrite or ReadOnly (restores only, no deletion).
spec.syncPeriodduration1mHow often to validate and sync from storage, at least 10s. 0s disables sync.
status.phasestringAvailable or Unavailable.
status.messagestringWhy it's unavailable, or a sync error.
status.lastValidationTime, status.lastSyncTimetime

Backup#

Exactly one of postgres and bucket must be set.

FieldTypeDefaultDescription
spec.storageLocationstringName of a BackupStorageLocation in the same namespace. Required.
spec.ttldurationoperator default (720h)Delete the backup and its data this long after completion. 0s keeps it.
spec.postgresPostgresConnection +Connection fields, plus:
spec.postgres.databases[]stringall, via pg_dumpallDatabases to dump one by one with pg_dump --format=custom.
spec.postgres.includeGlobalsboolfalseAlso dump roles and tablespaces (with databases).
spec.postgres.extraArgs[]stringAppended to pg_dump / pg_dumpall.
spec.bucketS3SpecThe bucket and prefix to copy.
spec.jobJobOptionsSettings for the backup Job.
status.phasestringNew, InProgress, Completed, Failed, Deleting.
status.messagestringError of a failed backup.
status.locationstrings3://bucket/prefix/backups/name/
status.startTimestamp, .completionTimestamp, .expirationtime
status.sizeBytes, status.itemsintBytes uploaded; dump files or objects stored.
status.files[]stringDump files, relative to the location (PostgreSQL only).
status.jobNamestringThe Job that ran it.

Annotations: planb.sina-devel.github.io/retain-data: "true" keeps the data on deletion; …/synced-from-storage marks imported backups; …/notified lists Notifiers that sent a message. Labels: …/storage-location, …/schedule.

Notifier#

Exactly one of webhook, slack, telegram and email must be set. SecretKeyRef is {name, key}.

FieldTypeDefaultDescription
spec.events[]string[BackupFailed, RestoreFailed]Any of BackupCompleted, BackupFailed, RestoreCompleted, RestoreFailed.
spec.selectorLabelSelectoreverythingOnly Backups/Restores with matching labels.
spec.suspendboolfalseStop sending.
spec.webhook.url | .urlSecretstring | SecretKeyRefWhere to POST the JSON message.
spec.webhook.headersmapExtra request headers.
spec.slack.webhookURLSecretKeyRefIncoming webhook URL.
spec.slack.channelstringChannel override.
spec.telegram.botTokenSecretKeyRef
spec.telegram.chatIDstringUser, group or @channel.
spec.telegram.apiURLstringhttps://api.telegram.org
spec.email.host, .portstring, intport 587SMTP server.
spec.email.tlsstringStartTLSStartTLS, TLS or None.
spec.email.skipTLSVerifyboolfalse
spec.email.from, .tostring, []string
spec.email.credentials{name, usernameKey, passwordKey}keys username/passwordSMTP AUTH PLAIN.
